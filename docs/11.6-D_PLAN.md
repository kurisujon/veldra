# Phase 11.6-D Plan

Goal: Refactor Gemini into a Layer 2 interpreter/indexer.

1. **Modify `src/lib/ai/schemas.ts`**:
   - Change `EvidenceFieldSchema` to expect `value`, `state` (candidate/not_present/unreadable/ambiguous), and `evidenceSpanIds`.

2. **Modify `src/lib/ai/prompts.ts`**:
   - Update `ANTI_HALLUCINATION_RULES` and `EVIDENCE_FIELD_SCHEMA`.
   - Instead of just `OCR REFERENCE TEXT`, provide a structured list of spans: `[span_001] "TEXT"` so Gemini can reference them.

3. **Modify `src/lib/ai/extraction.ts`**:
   - Instead of passing raw `ocrResult.fullText` to Gemini, pass the `CanonicalEvidenceMap` (or `EvidenceMap`). Wait, in 11.6-C we built `EvidenceMap.fromCanonicalProviderMap`. We can use this to generate the reference text for Gemini.
   - For backward compatibility with the rest of the pipeline until 11.6-E (Evidence Validator), `extraction.ts` will take the `evidenceSpanIds` returned by Gemini, look them up in the `EvidenceMap`, and populate the legacy `sourceText`, `page`, and `confidence` fields so the rest of the pipeline (like `validateEvidence`) doesn't crash.

4. **Preserve 11.6-A/B/C**:
   - Do not break the `EvidenceMap` or DB integration.
